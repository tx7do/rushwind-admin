# RushWind Admin 渐进教程

面向"从零接手本项目"的开发者：按序读完，你会从一个空环境走到能独立实现服务模块、理解全部横切系统、并把系统安全部署上线。

**本系列的定位**：讲**路径与概念**，每章末尾的「深读」链到参考层文档（`docs/*.md`）拿细节。
两层冲突时以参考层与代码为准，欢迎修订教程。

## 阅读路线

- **全栈采用者**（拿本基座做自己产品）：01 → 02 → 03 → 04 → 05 → 06 → 08 → 09；07 按需。
- **后端开发者**：01 → 02 → 03 → 04 → 06 → 07，再按子系统读参考层。
- **前端开发者**：01 → 02 → 03（重点 TS 客户端面）→ 05，再读 `frontend/admin/react` 内的说明文档。
- **运维 / 安全**：01 → 02 → 07 → 08。
- **给本仓提 PR 的贡献者**：全部教程 + 根 [`CONTRIBUTING.md`](../../CONTRIBUTING.md)（仓库约定以 CONTRIBUTING 为准）。

## 约定

1. 本系列只做"路径与概念"，机制细节一律以参考层文档为权威（清单见 [docs/README.md](../README.md)）；
2. 功能变更：改参考层，检查本系列链接是否仍成立；
3. 发现章节内容与代码不符：以代码与参考层为准修章节，并在 PR 注明；
4. 新增横切系统时：既加参考层文档，也在 01 章地图与对应章补一行。
